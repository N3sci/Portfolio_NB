# Nicolò Bedetti | Product Designer

Welcome to my personal product design portfolio repository. This website showcases a curation of my recent projects across industrial design, exhibition design, and furniture design.

## 🚀 Projects Included

*   **Ghianda:** Active seating and stretching tool (Technogym collab).
*   **Ottoman:** Unusual and provocative stool design.
*   **Zir:** Reinterpretation of a traditional children's toy (MET Museum).
*   **Mimmo:** Beach umbrella 2.0.
*   **Pickup:** Modular interchangeable toy (IKEA project).
*   **Oltre La Soglia:** Immersive exhibition design (Ex-Teatro Verdi).

## 🛠 Tech Stack

This portfolio is built with a focus on modern aesthetics, smooth performance, and premium interactions:
*   **HTML5 / CSS3**
*   **Tailwind CSS** (for responsive and rapid styling)
*   **Vanilla JavaScript**
*   **GSAP (GreenSock)** (for fluid scroll animations and entrance effects)
*   **Lucide Icons**

## 🎨 Design Philosophy

The interface is designed to emulate a premium editorial layout. Key features include:
*   Minimalist dark mode aesthetic (`#080808` background)
*   Custom fluid cursor for enhanced interaction
*   Dynamic 3D wireframe canvas animation
*   Bento-grid masonry layouts for responsive image galleries
